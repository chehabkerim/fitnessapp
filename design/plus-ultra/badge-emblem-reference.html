Badge emblem reference (enamel pin)

Source of truth for the badge emblem. Reproduce this geometry and these gradients exactly in the app's Badge component (react-native-svg).
- viewBox -4 -2 108 144. Hexagon path M50 4 L94 29 L94 83 L50 108 L6 83 L6 29 Z (shield alternative is in the source but not used).
- Layers, back to front: blurred drop shadow (offset y 3), metal rim (full shape, tier gradient), inner bevel (shape scaled 0.92 about 50,56, reversed gradient),
  enamel (scaled 0.84, radial purple #4A2466 to #170A22), 0.5-opacity dark edge on the enamel, faint top-left sheen, icon (dark copy offset 2 below, then metal), stars, diamond sparkles, number bar.
- Icons: FILLED set for all except "loop" (Full Rotation) and "return" (Comeback), which use the OUTLINE set. Icons are centred on (50, 55.2) and drawn via <use> at x -8, y -8, 116 x 130 (scale ~1.16).
- Stars: one per tier (1-4), on an arc centred (50, 55.2), radius 31, 21 degrees apart, centred on the top; star radius 4.2, each rotated to follow the arc. Filled with the tier metal.
- Tier metals: bronze, silver, gold, diamond (see gradients). Diamond adds three small white sparkles. Locked = gunmetal rim, dark enamel, grey icon, no stars.
- Number bar below the emblem at y 115: metal frame 22 high, enamel inset, number in Barlow Condensed 800 italic 15, off-white (locked: #8A8C92).
- Earn animation: a white diagonal shine sweeps across the emblem once (clip to the shape), ~1.3 s.

Tiers: bronze, silver, gold, diamond, locked

class Component extends DCLogic {
  star(cx, cy, r, rot) {
    const pts = [];
    for (let i = 0; i < 10; i++) {
      const a = -Math.PI / 2 + (i * Math.PI) / 5 + (rot || 0), rr = i % 2 ? r * 0.45 : r;
      pts.push(`${(cx + rr * Math.cos(a)).toFixed(2)} ${(cy + rr * Math.sin(a)).toFixed(2)}`);
    }
    return 'M' + pts.join(' L') + ' Z';
  }
  renderVals() {
    const tier = Math.max(1, Math.min(4, this.props.tier ?? 4));
    const top = (this.props.topTier ?? 'Diamond') === 'Platinum' ? 'platinum' : 'diamond';
    const earned = this.props.earned ?? true;
    const shield = (this.props.shape ?? 'Hexagon') === 'Shield';
    const size = this.props.size ?? 200;
    const number = String(this.props.number ?? '50');
    const n = number.length;
    const metalName = earned ? ['bronze', 'silver', 'gold', top][tier - 1] : 'locked';
    const enamelName = !earned ? 'locked' : (this.props.enamel ?? 'Purple') === 'Black' ? 'black' : 'purple';
    const plateW = Math.max(40, n * 8.5 + 20);
    const show = (b) => (b ? 'inline' : 'none');
    const arc = (i) => { const a = (-90 + (i - (tier - 1) / 2) * 21) * Math.PI / 180; return this.star(50 + 31 * Math.cos(a), 55.2 + 31 * Math.sin(a), 4.2, a + Math.PI / 2); };
    return {
      w: size, h: Math.round(size * 1.333), number, fs: n <= 4 ? 15 : 13,
      plateW, plateX: 50 - plateW / 2, plateInW: plateW - 3.2, plateInX: 51.6 - plateW / 2,
      shapePath: shield ? 'M50 4 L92 16 L92 52 C92 80 72 98 50 108 C28 98 8 80 8 52 L8 16 Z' : 'M50 4 L94 29 L94 83 L50 108 L6 83 L6 29 Z',
      clip: shield ? 'url(#pp-clip-shield)' : 'url(#pp-clip-hex)',
      metal: `url(#pp-m-${metalName})`, bevel: `url(#pp-b-${metalName})`, enamel: `url(#pp-e-${enamelName})`,
      iconRef: ((this.props.iconStyle ?? 'Filled') === 'Filled' && !['loop', 'return'].includes(this.props.icon ?? 'bolt') ? '#pp-if-' : '#pp-ic-') + (this.props.icon ?? 'bolt'), iconColor: earned ? `url(#pp-m-${metalName})` : '#6A6C72', iconOpacity: 1,
      starsDisp: show(earned), s1: arc(0), s2: arc(1), s3: arc(2),
      s4: arc(3), s1Disp: show(tier >= 1), s2Disp: show(tier >= 2), s3Disp: show(tier >= 3), s4Disp: show(tier >= 4),
      sparkDisp: show(earned && tier >= 4 && top === 'diamond'),
      shineDisp: show(earned && (this.props.shine ?? true)), numColor: earned ? '#F4F1EA' : '#8A8C92',
      label: this.props.label ?? number,
    };
  }
}
